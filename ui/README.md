# ToolNG application surface

This directory contains a browser-based product design prototype derived from the abstract sketch: a system/status rail, a large open work field, spatially arranged connected nodes, contextual inspection and a lower action dock.

## Product-specific interpretation

A read-only diagnostic surface that separates what was observed from what remains unknown.

The design is tailored to the actual repository role and uses its own palette and interaction density. The graph is a visual explanation of domain data, not a generic card dashboard.

## Preview

Open `index.html` in a modern browser. No build step or external runtime is required.

## Boundaries

All values are illustrative preview data. This web view does not invoke the native ToolNG implementation, inspect local devices or execute host actions. It must not be treated as engineering, hardware or runtime evidence.
