# 🦆 ToolzNG Duck Brand

## Identity

The ToolzNG mascot is a golden rubber duck engineer wearing dark glasses. It signals a friendly, careful utility rather than a system-modification tool.

## Palette

| Token | Hex | Use |
|---|---|---|
| Midnight | `#0D0E13` | Main window background |
| Graphite | `#1B1C25` | Panels and navigation |
| Duck Gold | `#FFBF33` | Primary accent and mascot |
| Orange | `#EF7E23` | Beak and small highlights |
| Warm White | `#F6F2E7` | Main text |
| Muted Stone | `#AEA99D` | Secondary text |
| Status Green | `#53CB97` | Positive diagnostic states |

## UI rules

- The duck is decorative. Never place it over device identifiers, status text, or warnings.
- Use gold for navigation emphasis and primary actions, not for every surface.
- Keep cards calm and readable; prioritize diagnostic information over decoration.
- Use the SVG mascot in documentation and the GDI-rendered mascot in the native C application.
- Do not present the product as an iOS overclocking or cache-cleaning tool. Describe only features that the code implements.
