# Octopus Ippon Release — ToolNG

Project profile: Windows host-side, read-only device evidence utility.

Release gates: Windows CMake Release build; repository contract checker; source archive; SPDX SBOM; SHA-256 manifest; GitHub build-provenance attestation. No driver installation, device repair, service mutation, private backup inspection or cloud upload is performed by CI.

A version tag publishes the verified evidence bundle as a GitHub Release. This is a source/evidence release until a stable, documented executable packaging target is proven. The 666 iteration programme tracks actual fixes and tests; it is not a count of successful runs.
