# Satan node registration

This repository is registered with the Satan Nexus control plane in
[bboroski/SAMBU](https://github.com/bboroski/SAMBU/tree/feature/satan-qegm-autonomous-core).

The manifest in this directory is declarative. It does not install a network
listener, add runtime dependencies, alter build or deployment behavior, or
grant credentials. The central package defines the event envelope and policy
contract. A local adapter will be added only after this repository's language,
entry points, test commands, and CI constraints have been inspected.

All proposed changes remain reviewable Pull Requests. No automatic merge or
production deployment is enabled.
